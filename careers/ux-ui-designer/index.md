  <h2>What does a UX/UI Designer do?</h2>
  <p>
    UX/UI Designers help create digital experiences that are useful,
    understandable and easy to use. UX focuses on the experience and user
    needs, while UI focuses on the visual interface.
  </p>

  <h2>Core skills</h2>
  <ul>
    <li>UX fundamentals</li>
    <li>UI design</li>
    <li>User-centered thinking</li>
    <li>Visual communication</li>
    <li>Digital product design</li>
  </ul>
