      <span class="eyebrow">THE PATH</span>

      <h2>Understand security before specializing.</h2>

      <p>
        Cybersecurity covers many disciplines. A broad foundation makes it
        easier to understand where you want to go next.
      </p>
    </div>

    <div class="steps-grid">

      <div class="step">
        <span class="step-number">01</span>
        <h3>Security Fundamentals</h3>
        <p>
          Learn the basic principles of confidentiality, integrity,
          availability, threats and risk.
        </p>
      </div>

      <div class="step">
        <span class="step-number">02</span>
        <h3>Networking</h3>
        <p>
          Understand how devices, networks and common protocols
          communicate.
        </p>
      </div>

      <div class="step">
        <span class="step-number">03</span>
        <h3>Threats & Attacks</h3>
        <p>
          Learn about common attack patterns, vulnerabilities and security
          risks.
        </p>
      </div>

      <div class="step">
        <span class="step-number">04</span>
        <h3>Security Awareness</h3>
        <p>
          Understand practical security behaviors and how organizations
          reduce human-related risks.
        </p>
      </div>

      <div class="step">
        <span class="step-number">05</span>
        <h3>Ethical Hacking Foundations</h3>
        <p>
          Learn the principles behind authorized security testing and
          vulnerability assessment.
        </p>
      </div>

    </div>
  </div>
</section>
